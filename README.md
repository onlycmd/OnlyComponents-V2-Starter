# 🚀 Discord.js Components V2 - Boş Altyapı

Selamlar! Bu proje, Discord'un en yeni ve modern arayüz mimarisi olan **Components V2 (Bileşenler V2)** üzerine kurulmuş, tertemiz bir başlangıç altyapısıdır. Artık klasikleşmiş Embed yapısını bir kenara bırakıp, Discord'un sunduğu bu yeni modüler sistemi kullanıyoruz.

### ✨ Neler Var?
- **Embed Yok, Container Var:** Tüm mesajlar `ContainerBuilder`, `SectionBuilder` ve `TextDisplayBuilder` ile oluşturuldu.
- **Otomatik Deploy:** Botu başlattığınızda slash komutları otomatik olarak Discord API'sine kaydedilir.
- **Dinamik Yükleyici:** Komutlar (`commands/`) ve Eventler (`events/`) otomatik olarak yüklenir.
- **Modern Görünüm:** Profesyonel bir ping komutu örneği ile birlikte gelir.

### 🛠️ Kurulum
1. Projeyi bilgisayarınıza indirin.
2. Terminale `npm install` yazarak gerekli kütüphaneleri kurun.
3. `.env` dosyasını açıp kendi Bot Token, Client ID ve Guild ID bilgilerinizi girin.
4. `node index.js` komutu ile botu ateşleyin!
